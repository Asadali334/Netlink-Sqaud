Basic Networking Cable Details

Ethernet Cable (RJ45)

Used to connect computers, routers and switches in LAN networks.

Telephone Cable (RJ11)

Used for landline phones and DSL modem connections.

Fiber Optic Cable

Transfers data using light and provides ultra-high speed.

Coaxial Cable

Used for CCTV, cable TV, and broadband internet.

UTP Cable

Common LAN cable without shielding; low-cost and reliable.

STP Cable

Shielded cable used in high-interference environments.

Console Cable

Used to configure routers and switches via terminal port.
