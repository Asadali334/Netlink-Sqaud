Networking Devices

Explore the devices that build modern computer networks.

Devices Used in Networking

🔹 Router

  • Connects networks together
  • Assigns IP via DHCP
  • Performs NAT
  • Routes packets between networks

    • 📘 Explanation

  • A router connects multiple networks and intelligently chooses the best path for data packets. It works like a traffic manager between your local network and the internet.

🔹 Switch

  • Connects multiple devices
  • Operates at Layer 2
  • Uses MAC address table
  • Supports VLANs

    • 📘 Explanation

  • A switch sends data only to the device it is meant for using MAC address lookup. It improves speed and avoids unnecessary broadcasting.

🔹 Firewall

  • Blocks unauthorized traffic
  • Monitors network packets
  • Enhances data security

    • 📘 Explanation

  • A firewall protects your network like a security guard. It checks every packet and allows only safe traffic to enter your network.

🔹 Bridge

  • Divides large networks
  • Reduces excess traffic
  • Filters data using MAC
  • Improves performance

    • 📘 Explanation

  • A bridge connects two parts of a network to reduce congestion. It decides which traffic should pass and which should stay in its segment.

🔹 Hub

  • Connects multiple devices
  • Broadcasts data to all ports
  • Expands small networks
  • Low-cost device

    • 📘 Explanation

  • A hub sends data to every device, even if only one device needs it. This causes collisions and slows down the network.

🔹 Repeater

  • Extends signals
  • Boosts weak signals
  • Prevents data loss
  • Increases network range

    • 📘 Explanation

  • Repeaters amplify weak network signals to extend cable distance without loss of quality
