Network Requirements

📌 5 Computers Network

• 1 Switch (8-Port)
• Cat6 Cables
• Basic Router
• IP Scheme (192.168.1.x)

[ PC ] — [ Switch ] — [ Router ] — Internet

📌 20 Computers Network

• 1 Switch (24-Port)
• Firewall
• Server (DHCP + File)
• VLAN Setup

PCs → 24-Port Switch → Firewall → Router → Internet
Server → Switch (Separate VLAN)

📌 50+ Computers Network

• L3 Switch
• Multiple VLANs
• Advanced Routing
• Load Balancing Routers
• UPS System

VLAN-10 → Students
VLAN-20 → Admin
VLAN-30 → Servers
All Connected → L3 Switch → Firewall → Router

📌 100 Computers Network

• 2× 48-Port Managed Switches
• 1× 24-Port Backup Switch
• Layer 3 Core Switch
• Redundant Firewall System
• Centralized Server Rack
• VLAN Segmentation (5–7 VLANs)
• Fiber Backbone Connectivity

VLAN-10 → Staff PCs
VLAN-20 → Student PCs
VLAN-30 → Servers
VLAN-40 → CCTV
VLAN-50 → WiFi APs

All VLANs → Dual 48-Port Switches → L3 Core → Firewall Cluster → Router → Internet
